# Encryption & Decryption Tool 🔐

A simple Python-based encryption and decryption tool that uses the Caesar Cipher technique to demonstrate basic encryption concepts and data protection.

## Project Overview

This project implements a Caesar Cipher that allows users to enter text and a shift value. The program encrypts the text by shifting alphabetic characters and then decrypts the encrypted text back to its original form.

## Features

- Encrypts user-provided text
- Decrypts encrypted text
- Uses a user-selected shift value
- Preserves uppercase and lowercase letters
- Preserves spaces and non-alphabetic characters
- Displays both encrypted and decrypted output

## Technologies Used

- Python 3
- Ubuntu Linux
- Visual Studio Code
